# Security policy

apü is in beta. Please report vulnerabilities privately — not in public issues — via GitHub's
"Report a vulnerability" (Security → Advisories) on https://github.com/michaellocher/apue, or by
e-mail to the maintainer listed in package.json. Include a reproduction if you can. You will get an
answer within a week; fixes are released as patch versions and listed in CHANGELOG.md.

Supported versions: the latest beta release.
