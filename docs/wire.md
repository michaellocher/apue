# apü on the wire

Real requests against `examples/todo` (HTTP/2 via curl), generated by `docs/wire.sh`.
`i=` is the RFC 8785 canonical JSON input, `s=` a field selection.

### Discovery: RFC 9727 API catalog

```console
$ curl -s --http2 --cacert certs/cert.pem https://localhost:18443/.well-known/api-catalog
{"linkset":[{"anchor":"https://localhost:18443/","service-desc":[{"href":"https://localhost:18443/.well-known/apue","type":"application/json"}]}]}
```

### Unsafe op: POST + Idempotency-Key

```console
$ curl -s --http2 --cacert certs/cert.pem -i -X POST -H 'content-type: application/json' -H 'idempotency-key: "demo-1"' -d '{"title":"buy milk"}' https://localhost:18443/todos.create
HTTP/2 200 
content-type: application/json
cache-control: no-store

{"id":1,"title":"buy milk","done":false}
```

### Retry with the same key: replayed, not executed again

```console
$ curl -s --http2 --cacert certs/cert.pem -i -X POST -H 'content-type: application/json' -H 'idempotency-key: "demo-1"' -d '{"title":"buy milk"}' https://localhost:18443/todos.create
HTTP/2 200 
content-type: application/json
cache-control: no-store
apue-replayed: ?1

{"id":1,"title":"buy milk","done":false}
```

### Safe op: GET with canonical input — ETag, Cache-Control, Accept-Query

```console
$ curl -s --http2 --cacert certs/cert.pem -i 'https://localhost:18443/todos.get?i=%7B%22id%22%3A1%7D'
HTTP/2 200 
accept-query: "application/json"
content-type: application/json
cache-control: no-cache
etag: "wknydwJzvZ1RXhXqTUxSmI"

{"id":1,"title":"buy milk","done":false}
```

### Conditional GET → 304

```console
$ curl -s --http2 --cacert certs/cert.pem -i -H 'if-none-match: "wknydwJzvZ1RXhXqTUxSmI"' 'https://localhost:18443/todos.get?i=%7B%22id%22%3A1%7D'
HTTP/2 304 
accept-query: "application/json"
cache-control: no-cache
etag: "wknydwJzvZ1RXhXqTUxSmI"

```

### Field selection

```console
$ curl -s --http2 --cacert certs/cert.pem 'https://localhost:18443/todos.get?i=%7B%22id%22%3A1%7D&s=title'
{"title":"buy milk"}
```

### QUERY (RFC 10008) for reads with a body

```console
$ curl -s --http2 --cacert certs/cert.pem -i -X QUERY -H 'content-type: application/json' -d '{"id":1}' https://localhost:18443/todos.get
HTTP/2 200 
accept-query: "application/json"
content-type: application/json
cache-control: no-cache
etag: "wknydwJzvZ1RXhXqTUxSmI"

{"id":1,"title":"buy milk","done":false}
```

### Validation error → 400 problem details (RFC 9457)

```console
$ curl -s --http2 --cacert certs/cert.pem -i -X POST -H 'content-type: application/json' -d '{"title":""}' https://localhost:18443/todos.create
HTTP/2 400 
content-type: application/problem+json
cache-control: no-store

{"type":"https://apue.dev/problems/validation-failed","fields":[{"path":"title","message":"shorter than 1"}],"title":"Validation Failed","status":400,"detail":"input does not match the schema"}
```
