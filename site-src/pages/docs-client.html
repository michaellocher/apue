Client reference

ApueClient is typed from the API definition — no code generation — and runs in Node and in browsers (web-platform APIs only; transports are pluggable). Source: src/client.ts, src/transport-http2.ts, src/transport-ws.ts.

A transport is a small interface — request({ method, path, headers, body, signal }) returning status, headers and a body iterable, plus optional close() and baseUrl — so you can supply your own.

In the browser

There is no bundle yet. The todo example’s server type-strips src/*.ts on request, and its page imports them directly:

{{pre:ts|examples/todo/index.html (excerpt)}} import { ApueClient, fetchTransport } from '/src/client.ts'; import { autoTransport } from '/src/transport-ws.ts'; import { todoApi } from '/examples/todo/api.ts'; const client = new ApueClient(todoApi, fetchTransport(location.origin)); const uploads = new ApueClient(todoApi, autoTransport(location.origin)); await client.call('todos.create', { title }); // validated before sending, retried safely (Idempotency-Key) const [count] = await Array.fromAsync(uploads.duplex('todos.import', titles())); {{/pre}}

Errors

Every failure is thrown as an ApueError with status and problem (RFC 9457 fields plus extensions). Client-side validation failures are 400 validation-failed without a request being sent; an unknown operation name is 404; undecodable or truncated responses are 502. A cancelled call rejects with your signal’s reason. See Errors.
