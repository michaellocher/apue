Getting started

Install the package, then build a small API: one cacheable read and one server stream, called from a typed client and from curl.

{{toc}}

Install

{{pre:console|a new project}} $ npm init -y && npm pkg set type=module $ npm install apue@beta {{/pre}}
  • Node ≥ 26.11 for the server and the Node client. Node runs your .ts files directly (type stripping) — no build step. The package itself ships JavaScript and type declarations.
  • The web-safe core (apue, apue/websocket) runs in browsers too. No runtime dependencies.
  • A TLS certificate: apü servers speak HTTP/2 over TLS (with HTTP/1.1 fallback). For local development, a self-signed one will do (below).
Beta

0.1.0-beta releases may still change the wire format and APIs. Every change is listed in the changelog that ships with the package (node_modules/apue/CHANGELOG.md).

A first API

Three files in your project: a contract shared by server and clients, a server, and a client. Create a certificate for localhost first:

{{pre:sh|certs/}} mkdir -p certs && openssl req -x509 -newkey ec -pkeyopt ec_paramgen_curve:prime256v1 -nodes -days 365 \ -keyout certs/key.pem -out certs/cert.pem -subj /CN=localhost \ -addext subjectAltName=DNS:localhost,IP:127.0.0.1 {{/pre}}

3. A typed client

In Node, http2Transport uses node:http2 (full duplex). The client validates input before sending and output after receiving. In browsers, use fetchTransport from apue or autoTransport from apue/websocket — see the client reference.

The same calls with curl

A safe operation is a GET whose input is canonical JSON (RFC 8785) in ?i=. The response is cacheable for the 60 seconds the contract declares and carries a strong ETag:

{{pre:console}} $ curl -i --cacert certs/cert.pem 'https://localhost:8443/greetings.get?i=%7B%22name%22%3A%22Ada%22%7D' HTTP/2 200 accept-query: "application/json" content-type: application/json cache-control: public, max-age=60 etag: "6Rw7uGkU5twQHJtUgjQCBL" content-length: 22 {"text":"Hello, Ada!"} {{/pre}}

Invalid input is a 400 with RFC 9457 problem details naming the field:

{{pre:console}} $ curl -i --cacert certs/cert.pem 'https://localhost:8443/greetings.get?i=%7B%22name%22%3A%22%22%7D' HTTP/2 400 content-type: application/problem+json cache-control: no-store {"type":"https://apue.dev/problems/validation-failed","fields":[{"path":"name","message":"shorter than 1"}],"title":"Validation Failed","status":400,"detail":"input does not match the schema"} {{/pre}}

Streams are binary frames by default (application/vnd.apue.frames). For curl and devtools, ask for text/event-stream and get the same stream rendered as server-sent events:

{{pre:console}} $ curl --cacert certs/cert.pem -H 'accept: text/event-stream' 'https://localhost:8443/greetings.count?i=%7B%22to%22%3A3%7D' event: msg data: {"n":1} event: msg data: {"n":2} event: msg data: {"n":3} event: end data: {"status":200} {{/pre}}

These outputs are from running the files above (some response headers omitted).
