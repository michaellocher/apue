Getting started

Run the example app, then build a small API of your own: one cacheable read and one server stream, called from a typed client and from curl.

{{toc}}

Requirements

  • Node ≥ 26.11. The implementation is TypeScript run natively by Node (type stripping) — there is no build step.
  • openssl: apü servers speak TLS (HTTP/2 with HTTP/1.1 fallback), and the tests and example generate a throwaway self-signed certificate.
  • Optional: Chrome or Firefox (and npx playwright-core install webkit for WebKit) for the real-browser tests; Docker for the constrained benchmarks and the proxy probes.
No package yet

apü is not published to npm. Everything runs from a checkout of the (currently private) research repository; your code imports the modules under src/ directly, the way examples/todo does.

Run the example

The todo example serves a web page and its API from one origin. The browser imports src/*.ts, type-stripped by the example server — no bundler.

{{pre:sh|repository root}} node examples/todo/server.ts # https://localhost:8443 — open it in a browser (self-signed cert) node examples/todo/cli.ts # typed calls, a pipelined batch, a resumable change stream {{/pre}}

The first start writes a certificate to certs/ (git-ignored); bring your own with mkcert if your browser should trust it. npm run certs creates one with openssl as well.

Develop and test

{{pre:sh}} npm install # dev only: typescript + @types/node (typecheck), @grpc/* (gRPC benchmark) npm test # node --test, incl. headless Chrome, Firefox, WebKit (skipped if absent) npm run typecheck # tsc (noEmit, erasableSyntaxOnly) node bench/run.ts # benchmarks vs raw node:http2 baselines (separate processes) bench/docker.sh # same on CPU/RAM-limited containers, incl. emulated WAN (netem) bench/proxy/run.sh # behaviour through real nginx, Caddy, HAProxy and Envoy (Docker) {{/pre}}

At draft 01 the suite has 348 tests and runs in about 20 seconds.

A first API

Create examples/hello/ in your checkout, so that the imports below resolve to src/ like the todo example’s do.

1. The contract

An operation has a dotted name, an effect, an optional stream kind, and schemas for input and output. The file is plain TypeScript, shared by server and clients.

2. The server

Handlers<typeof api> types every handler from the contract: unary handlers return a value (or a promise), streaming handlers return an async iterable. ctx.signal fires when the client goes away or the deadline passes.

3. A typed client

In Node, http2Transport uses node:http2 (full duplex). The client validates input before sending and output after receiving.

The same calls with curl

A safe operation is a GET whose input is canonical JSON (RFC 8785) in ?i=. The response is cacheable for the 60 seconds the contract declares and carries a strong ETag:

{{pre:console}} $ curl -i --cacert certs/cert.pem 'https://localhost:8443/greetings.get?i=%7B%22name%22%3A%22Ada%22%7D' HTTP/2 200 accept-query: "application/json" content-type: application/json cache-control: public, max-age=60 etag: "6Rw7uGkU5twQHJtUgjQCBL" content-length: 22 {"text":"Hello, Ada!"} {{/pre}}

Invalid input is a 400 with RFC 9457 problem details naming the field:

{{pre:console}} $ curl -i --cacert certs/cert.pem 'https://localhost:8443/greetings.get?i=%7B%22name%22%3A%22%22%7D' HTTP/2 400 content-type: application/problem+json cache-control: no-store {"type":"https://apue.dev/problems/validation-failed","fields":[{"path":"name","message":"shorter than 1"}],"title":"Validation Failed","status":400,"detail":"input does not match the schema"} {{/pre}}

Streams are binary frames by default (application/apue+json). For curl and devtools, ask for text/event-stream and get the same stream rendered as server-sent events:

{{pre:console}} $ curl --cacert certs/cert.pem -H 'accept: text/event-stream' 'https://localhost:8443/greetings.count?i=%7B%22to%22%3A3%7D' event: msg data: {"n":1} event: msg data: {"n":2} event: msg data: {"n":3} event: end data: {"status":200} {{/pre}}

These outputs are from running the files above against the reference implementation (some response headers omitted).
