Server reference

The server runs on node:http2 (Node ≥ 26.11): HTTP/2 over TLS with HTTP/1.1 fallback, WebSockets over RFC 8441 and HTTP/1.1 Upgrade. Import it from apue/server; t.download() sources come from apue/downloads.

A missing handler, an invalid option or an API that needs uploads without the uploads option throws at creation. Note the default host: listen() binds to loopback unless you pass one.

Limits are validated as positive integers at startup. A “client” is its principal, or its address without a principal hook.

Idempotency stores

Every non-safe unary call with an Idempotency-Key goes through the store. Its scope is the operation, the caller (the principal, else a hash of Authorization) and the key; the fingerprint is the SHA-256 of the canonical input.

MethodContract
begin(key, fingerprint)Atomically claims the key, or reports why it can’t: { state: 'new' }, 'replay' with the stored response, 'in-progress' (answered 409, retryable) or 'mismatch' (another payload: 422)
complete(key, response)Stores the final response { status, headers, body } of a claimed key. Handler 4xx are stored too
release(key)Releases a claimed key without storing (5xx, client aborts), so a retry executes again

Each method may return a promise. A store that fails to record a result is reported to the logger; the response stands. An example for several replicas: Deployment.

Serving the app: fallback and Exchange

Paths that are not operations or reserved paths go to fallback(exchange). The Exchange gives you method, url, headers, remoteAddress and send(status, headers, body?), among others — enough to serve the web app’s page and scripts, so page and API share one origin and need no CORS, or a health check for the load balancer.

Shutdown

close() waits for calls in flight at most shutdownGraceMs, then aborts the rest with a retryable 503 — as the response, or as an END frame for running streams — gives that one second to flush and drops the remaining connections. WebSocket calls close with 1001. It returns as soon as the last call is done; file-backed uploads in a per-process directory are removed.
