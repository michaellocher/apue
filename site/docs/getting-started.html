Getting started

Install the package, then build a small API: one cacheable read and one server stream, called from a typed client and from curl.

On this page

  • Install

  • The same calls with curl

Install

The beta installs straight from its GitHub release — no registry, no token. npm records the URL in package.json; to update, install the next release’s tarball from the releases page.

  • Node ≥ 26.11 for the server and the Node client. Node runs your .ts files directly (type stripping) — no build step. The package itself ships JavaScript and type declarations.
  • The web-safe core (@michaellocher/apue, @michaellocher/apue/websocket) runs in browsers too. No runtime dependencies.
  • A TLS certificate: apü servers speak HTTP/2 over TLS (with HTTP/1.1 fallback). For local development, a self-signed one will do (below).
Beta

0.1.0-beta releases may still change the wire format and APIs. Every change is listed in the changelog that ships with the package (node_modules/@michaellocher/apue/CHANGELOG.md).

A first API

Three files in your project: a contract shared by server and clients, a server, and a client. Create a certificate for localhost first:

1. The contract

An operation has a dotted name, an effect, an optional stream kind, and schemas for input and output. The file is plain TypeScript, shared by server and clients.

2. The server

Handlers<typeof api> types every handler from the contract: unary handlers return a value (or a promise), streaming handlers return an async iterable. ctx.signal fires when the client goes away or the deadline passes.

3. A typed client

In Node, http2Transport uses node:http2 (full duplex). The client validates input before sending and output after receiving. In browsers, use fetchTransport from @michaellocher/apue or autoTransport from @michaellocher/apue/websocket — see the client reference.

Client in another project?

The client needs the contract, not this file: apue-types generates the same module from the running server’s manifest (/.well-known/apue). It imports from @michaellocher/apue and exports api, so client.ts stays as it is. Rerun it when the API changes. For Python, Go, Java and Swift clients, see generated clients.
