Getting started

Run the example app, then build a small API of your own: one cacheable read and one server stream, called from a typed client and from curl.

Requirements

  • Node ≥ 26.11. The implementation is TypeScript run natively by Node (type stripping) — there is no build step.
  • openssl: apü servers speak TLS (HTTP/2 with HTTP/1.1 fallback), and the tests and example generate a throwaway self-signed certificate.
  • Optional: Chrome or Firefox (and npx playwright-core install webkit for WebKit) for the real-browser tests; Docker for the constrained benchmarks and the proxy probes.
No package yet

apü is not published to npm. Everything runs from a checkout of the (currently private) research repository; your code imports the modules under src/ directly, the way examples/todo does.

Run the example

The todo example serves a web page and its API from one origin. The browser imports src/*.ts, type-stripped by the example server — no bundler.

The first start writes a certificate to certs/ (git-ignored); bring your own with mkcert if your browser should trust it. npm run certs creates one with openssl as well.

Develop and test

At draft 01 the suite has 348 tests and runs in about 20 seconds.

A first API

Create examples/hello/ in your checkout, so that the imports below resolve to src/ like the todo example’s do.

1. The contract

An operation has a dotted name, an effect, an optional stream kind, and schemas for input and output. The file is plain TypeScript, shared by server and clients.

2. The server

Handlers<typeof api> types every handler from the contract: unary handlers return a value (or a promise), streaming handlers return an async iterable. ctx.signal fires when the client goes away or the deadline passes.

3. A typed client

In Node, http2Transport uses node:http2 (full duplex). The client validates input before sending and output after receiving.
