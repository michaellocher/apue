Documentation

apü is an API protocol in the family of REST, GraphQL and gRPC, defined purely in HTTP semantics (RFC 9110). An API is a set of named, typed operations; how each one travels over HTTP follows from what it declares.

Beta

These pages describe the toolkit @michaellocher/apue 0.1.0-beta (npm install @michaellocher/apue@beta) and draft 01 of the spec. Betas may still change the wire format and APIs; every change is listed in the changelog that ships with the package. Things marked in progress or blocked don’t exist yet.
