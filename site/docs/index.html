Documentation

apü is an API protocol in the family of REST, GraphQL and gRPC, defined purely in HTTP semantics (RFC 9110). An API is a set of named, typed operations; how each one travels over HTTP follows from what it declares.

Research draft

These pages describe draft 01 of the spec and its Node 26 reference implementation as of 2026-10-28. Things marked planned do not exist yet. The protocol may still change, and no package is published: you work from a checkout of the repository.
