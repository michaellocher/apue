Server reference

The reference server runs on node:http2 (Node ≥ 26.11): HTTP/2 over TLS with HTTP/1.1 fallback, WebSockets over RFC 8441 and HTTP/1.1 Upgrade. Source: src/server.ts.

createApueServer

A missing handler, an invalid option or an API that needs uploads without the uploads option throws at creation. Note the default host: listen() binds to loopback unless you pass one.

Limits are validated as positive integers at startup. A “client” is its principal, or its address without a principal hook.

Serving the app: fallback and Exchange

Paths that are not operations or reserved paths go to fallback(exchange). The Exchange gives you method, url, headers, remoteAddress and send(status, headers, body?), among others; the todo example uses it to serve its HTML page and the type-stripped src/*.ts modules, so page and API share one origin and need no CORS.

Shutdown

close() waits for calls in flight at most shutdownGraceMs, then aborts the rest with a retryable 503 — as the response, or as an END frame for running streams — gives that one second to flush and drops the remaining connections. WebSocket calls close with 1001. It returns as soon as the last call is done; file-backed uploads in a per-process directory are removed.

apü

An API protocol built on plain HTTP semantics. Research draft 01, October 2026 — not a stable standard, and no package is published yet.

The name is written apü; URLs, headers and media types use apue.
